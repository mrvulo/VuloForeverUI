## 0.20.0

**New**

- **Edit Mode** — window positions you set in this addon's Edit Mode are now
  also written into your own Blizzard Edit Mode layout when you close it, so
  both editors show the same place and a frame no longer jumps when the game
  reloads its layout (a level-up in combat did that). With a preset layout
  active you get a one-time hint to create a layout of your own.
- **Quality of Life** — trinket lists per talent set: each of your two specs
  keeps its own top and bottom trinket list and switches with it.
- **Quality of Life** — shift-click a trinket in the trinket grid to add it
  to the list or take it off (left button top slot, right button bottom
  slot); its rank shows on the icon.
- **Reminders** — consumables show how many you still carry and turn red
  when you run low ("Low stock from"), warn shortly before they run out, and
  can stay on the bar with a green check while active ("Show active ones
  with a check").

**Changed**

- **Quality of Life** — a higher-priority trinket goes back on once it is
  ready again; a trinket you put on by hand is left alone.
- **Resource Bars** — the width of the DoT bars can be set right in Edit
  Mode (Width slider in the frame panel); setting it there ends "Width like".
- **Bags** — the BoE tag shows on equipment only.
- **General** — thin edges and window borders are exactly one screen pixel
  at any UI scale.

**Fixed**

- **Bags** — dropping an item onto a bag button no longer causes a blocked
  action error.
- **Edit Mode** — windows docked to the player or target frame (for example
  the DoT bars) stay in place after a relog.
- **Edit Mode** — "Reset this frame" puts Blizzard's frames back on their
  default place instead of the screen centre.
- **Edit Mode** — the opacity sliders and the help text fit inside the frame
  panel.
- **Unit Frames** — in the Classic style the target's health value no longer
  jumps out next to the portrait in combat.
